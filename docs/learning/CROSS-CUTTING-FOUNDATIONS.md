## 三、17张完整学习卡：专业机制 + 类比 + 错误边界 + 动手验证

### X01 开发环境与命令行

**专业定义 / 机制**：代码靠环境执行：工作目录、解释器/运行时、PATH与环境变量共同决定命令行为。涉及：编辑器/调试器、文件系统、路径/PATH、Shell、进程和包管理器。

**大白话类比**：厨房开工前先确认用的是哪套工具、在哪间房和从哪个门进去。

**类比的边界**：不等同于Docker部署或会写Linux内核；Windows/WSL/macOS的命令可能不同。

**与42节点的关系**：E01。这里的P0基础是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Command_line)。

**动手实验（设计状态）**：在隔离目录用PowerShell或Bash创建/查找/删除文件，核对node/python/git路径与版本，跑失败命令并修复PATH。

**故障/负例**：PATH优先级选错解释器、工作目录错误、相对路径失效。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X02 数据结构、算法与复杂度

**专业定义 / 机制**：数据结构选择决定查询/插入/删除和空间代价；渐进复杂度用于说明输入规模增长时的资源变化。涉及：数组/列表、哈希表、集合、栈/队列、树/堆、排序/搜索、Big-O、空间复杂度。

**大白话类比**：找一本书，目录/索引比每次从第一页逐页翻快，但需要维护索引。

**类比的边界**：Big-O不等于实际毫秒；磁盘/网络/缓存与数据分布也影响真实性能。

**与42节点的关系**：F03、B03、P02。这里的P0基础是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)。

**动手实验（设计状态）**：用数组扫描和Map查找同一集合，跑不同规模对照、解释复杂度，并加重复键与空数据测试。

**故障/负例**：小规模测试快但规模扩大严重退化；错误哈希键/缺失键行为。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X03 调试器、断点、可复现最小案例

**专业定义 / 机制**：先让故障可重复，再用观察区分症状、传播链路和根因；日志/Trace/断点互补。涉及：断点、条件断点、调用栈、变量监视、浏览器Network/Performance、服务器日志与根因假设。

**大白话类比**：先拍下漏水位置、关几路阀门定位水管，而不是反复刷墙。

**类比的边界**：只会print不能替代调试；随机重试消失不代表根因修复。

**与42节点的关系**：F03、B02、E04。这里的P0基础是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://developer.chrome.com/docs/devtools/javascript/)。

**动手实验（设计状态）**：故意造成前端过期响应和后端400，分别用断点/调用栈/Network定位，留下复现命令与修复测试。

**故障/负例**：竞态有时不复现、仅修复表现未验证根因。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X04 Git分支、PR、Code Review与协作

**专业定义 / 机制**：版本控制表达可审查的变更历史；PR以差异、测试、授权审查守护主分支。涉及：commit/branch/rebase/merge/cherry-pick、PR review、冲突解决、可回滚提交与任务关联。

**大白话类比**：修订合同保留每版修改记录，合并前需要验收而不是直接改最终版。

**类比的边界**：Git提交成功不等于PR获批、CI通过或上线；rebase共享分支需谨慎。

**与42节点的关系**：E01、P01。这里的P0基础是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**动手实验（设计状态）**：两分支故意修改同一行制造冲突，解决后提PR并附测试证据，演练回退。

**故障/负例**：冲突误删同事修改、未经审查直接合并。

### X06 国际化、本地化、时区与金额

**专业定义 / 机制**：数据存储与UI展示的区域设置需要分离；本地时区/夏令时不是简单加8小时。涉及：Unicode/UTF-8、lang/dir、RTL、Intl.DateTimeFormat、IANA时区、货币最小单位/Decimal。

**大白话类比**：同一张机票的绝对起飞时刻，在各国售票屏幕上显示的时间不同。

**类比的边界**：用户当地日期、UTC时间戳和无时区日期不是同一类型；金额不用二进制浮点计算。

**与42节点的关系**：F02、F03、D01。这里的P1按需是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**动手实验（设计状态）**：同一UTC事件显示洛杉矶/上海，覆盖DST变化；中文/阿语表单与金额千分位/精度测试。

### X08 API生命周期、分页、版本与Webhook

### X10 威胁建模与安全验证基线

**类比的边界**：OWASP安全标准不是一次打勾即绝对安全；不在未知第三方系统做攻击测试。

### X11 依赖、密钥与软件供应链安全

**专业定义 / 机制**：生产依赖不只有应用源码，传递依赖/构建脚本和密钥访问同样影响系统风险。涉及：依赖锁定、最小权限令牌、Dependabot/依赖审查、SBOM、签名来源、许可证/漏洞响应。

**大白话类比**：采购的零件即使不是自己做的，也必须查来源、版本和质检单。

**类比的边界**：自动升级并不保证兼容；仓库公开/私有计划可能限制某些扫描功能。

**与42节点的关系**：E01、E02、E03。这里的P0交付是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://docs.github.com/en/code-security/concepts/supply-chain-security/supply-chain-security)。

**精确分主题资料**：[GitHub PR依赖审核](https://docs.github.com/en/code-security/concepts/supply-chain-security/dependency-review)。

**动手实验（设计状态）**：新增一个已知不安全或不合规的合成依赖并在隔离PR检查依赖审查，不上传真实密钥。

**故障/负例**：锁文件漂移、恶意上游包、CI令牌权限过大。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X12 个人数据、隐私与生命周期

**专业定义 / 机制**：从采集到备份和最终删除，数据都需要所有权、期限和访问策略。涉及：数据分类、最小收集、用途限制、留存/删除、备份与日志脱敏、导出及访问审计。

**大白话类比**：用户搬家退租，仓库备份和日志里也不能无限期保留旧钥匙。

**类比的边界**：本页不替代具体法域的合规评审，删除权实现会受法律保留要求约束。

**与42节点的关系**：E03、D01、P03。这里的P1持久化个人数据是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://asvs.owasp.org/)。

**精确分主题资料**：[NIST隐私框架](https://www.nist.gov/privacy-framework)。

**动手实验（设计状态）**：合成用户请求导出/删除，验证主表/对象/缓存/日志及备份恢复后的边界。

**故障/负例**：删主表但对象存储还可读、日志包含token/PII。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X13 SLO、事故响应与复盘

**专业定义 / 机制**：从用户可用性定义服务目标，故障时按可执行流程发现/止损/恢复/复盘。涉及：SLI/SLO、错误预算、RED/USE、告警阈值、事件分级、Runbook和无责复盘。

**大白话类比**：不只装温度计，还要规定超温谁负责、怎么降温和复发如何预防。

**类比的边界**：低访问量的小工具可以简化值班/告警，没数据不伪造可用性99.9%。

**与42节点的关系**：E04、P03。这里的P1生产服务是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://sre.google/workbook/table-of-contents/)。

**精确分主题资料**：[Google事故管理实践](https://sre.google/resources/practices-and-processes/incident-management-guide/)。

**动手实验（设计状态）**：隔离环境注入慢接口和断连，按运行手册定位，记录发现/恢复时间与改进项。

**故障/负例**：告警噪声导致没人看、只回滚镜像但数据库不可逆。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X14 容量、并发与云成本

**专业定义 / 机制**：吞吐上限由最窄的资源瓶颈决定，成本是架构的约束变量。涉及：CPU/RAM/磁盘/网络/连接池、压测与增长曲线、云资源/对象/模型调用成本。

**大白话类比**：餐厅能服务多少桌客人，看炉灶/桌位/服务员最慢的环节。

**类比的边界**：一次请求的时延不能外推真实高并发性能；高配云机器不自动解决锁争用。

**与42节点的关系**：P02、E04、P03。这里的P1按需是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://docs.aws.amazon.com/wellarchitected/latest/cost-optimization-pillar/welcome.html)。

**动手实验（设计状态）**：用相同负载对比连接池与CPU、外部API额度/成本，明确P95和拒绝率。

**故障/负例**：压测无上限导致额度消耗、流量变动使瓶颈迁移。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X15 域名、DNS、CDN、HTTPS与反向代理

**专业定义 / 机制**：域名把人类名称映射到服务入口，TLS验证和加密链路，代理分发请求。涉及：DNS记录TTL、域名解析、反向代理/证书/TLS终止、静态资源/CDN与网络边界。

**大白话类比**：门牌号决定到哪栋楼，证书确认大门身份，前台决定转哪个办公室。

**类比的边界**：CNAME不是HTTP重定向；DNS TTL不等于缓存一定立即一致；HTTPS不等于应用授权。

**与42节点的关系**：F01、E02。这里的P0上线是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://developers.cloudflare.com/dns/)。

**动手实验（设计状态）**：在隔离环境配置域名/模拟主机名、HTTPS和反代，观测错误DNS/证书链/超时。

**故障/负例**：证书过期、反代超时、CDN缓存泄露用户数据。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X16 环境配置、Secrets与发布切换

**专业定义 / 机制**：同一构建产物应能在环境约束下安全配置；发布可分阶段暴露并可撤销。涉及：dev/staging/prod配置分离、密钥轮换、Feature Flag、Schema迁移、灰度/回滚。

**大白话类比**：同一台机器开工前换正确说明书和钥匙，先在试运营区域开门。

**类比的边界**：环境变量不是万能密钥库；数据库Schema回滚不一定等于镜像回滚。

**与42节点的关系**：E02、E01、P03。这里的P0上线是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**故障/负例**：secret进入浏览器bundle、dev密钥发布到生产、标志位关闭但副作用仍执行。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

### X17 编码、JSON、时间与数值精度契约

**专业定义 / 机制**：跨系统字段不仅要类型相同，还要单位、精度、时间语义和空值约定一致。涉及：UTF-8、Unicode规范化、JSON序列化、Decimal/整数最小货币单位、RFC3339与时区偏移。

**大白话类比**：两队传同一张单据，要约好日期含不含时区、钱按元还是分记。

**类比的边界**：浮点数和货币、UTC瞬时值和本地日期混用会造成不一致；TypeScript编译不会修复语义偏差。

**与42节点的关系**：B01、F03、D01。这里的P0数据是按适用场景的认知优先级，**不是要求所有项目先把它完成**。

**权威资料**：[阅读官方/标准/课程原文](https://www.rfc-editor.org/rfc/rfc3339.html)。

**精确分主题资料**：[PostgreSQL精确numeric与浮点比较](https://www.postgresql.org/docs/current/datatype-numeric.html) · [JS Intl时区格式化](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat)。

**动手实验（设计状态）**：同一时间/金额字段经浏览器→API→数据库往返并对照，测0.1+0.2/空值/夏令时。

**故障/负例**：金额漂移、JSON整数超精度、非UTF-8输入、时区日期偏移。

**独立验收**：在授权的当前工程或隔离实验中复现、写断言、修复、换条件复测。必须留环境、源码commit、执行命令和真实日志；未执行保持 `UNASSESSED`。

## 四、把广度和深度分开

- **通用工程基础**：X01–X04建议先知道名称与基本概念，实际技能通过当前开发任务和故障复测加深。
- **浏览器与产品体验**：X05/X07在Web交付中优先考虑，X06在国际化/货币/全球时区被业务触发时深入。
- **接口与可交付质量**：X08–X11及X17贯穿多层，但任务简易程度不同；优先选择可重现的风险点。
- **真实生产/运营**：有私有用户数据时看X12，准备上线看X15/X16；具备实际服务目标与规模时再深入X13/X14。
- **每个专题的现有核心知识仍按需查阅**：[42节点知识图](KNOWLEDGE-GRAPH.md) / [专业学习卡](NODE-STUDY-CARDS.md) / [需求路由](DEMAND-ROUTER.md)。

**范围限制**：不存在适用于全部公司、全部产品的一张“100%无遗漏全栈清单”。支付监管、地图SDK、WebRTC、嵌入式、合规法域等场景有自身新知识，应登记GAP再扩张，而不是虚构已掌握。
