## 差异与本轮补全

- **旧图遗漏**：Vue3与Nuxt分支、桌面 Electron/Tauri、Node NestJS、Go/Rust/C++、WebSocket/MCP、构建打包等在上游有完整概念或课程入口。本轮把这些补入知识图及官方文档，不强制每个下游使用。
- **重复但缺少链接**：React/FastAPI、SQL/Redis、AuthZ、CI/部署已在全栈仓；本轮增加对应LAB和上游案例直达，避免复制第二份学习顺序。
- **方法论复用**：未知业务目标用 [BDL](https://github.com/Xander-Xai/X-SuperPlay-AI-Learning-OS/blob/main/prompts/business-demand-learning/v1.0.0/01-business-demand-to-learning-goals.md)，目标明确用 [ANL](https://github.com/Xander-Xai/X-SuperPlay-AI-Learning-OS/blob/main/prompts/ai-native-learning/v1.0.0/01-github-ai-learning-research.md)，真实实验用本仓[需求学习会话卡](GAP-SESSION-TEMPLATE.md)。
- **评分层级不同**：上游0–4是独立能力评分；本仓L1–L3是原理→代码→故障诊断。仅有文档/CI无法证明个人独立通过；保持两套原始尺度，不强行数字换算。
- **证据约束**：要区分上游已有资料、课程设计、模拟源码、CI通过、本人独立通过与真实产品授权。所有跨仓链接只读，当前下游授权按各仓自身状态判断。
